# create-nori

```bash
npm create nori@latest my-cart
cd my-cart && npm install
npm run pack        # → dist/my-cart-0.1.0.nori
```

NoriDeck 카트리지 프로젝트 뼈대를 만듭니다. `npx @nghslab/nori-cli init my-cart` 와 같습니다.
옵션: `--id <id>` `--title <제목>` `--force`

개발 가이드: https://github.com/NGHSLab/NoriDeck/blob/main/docs/cartridge-guide.md
